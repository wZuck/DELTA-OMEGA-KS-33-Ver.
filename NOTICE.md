# DELTA OMEGA KS-33 Ver. Modification Notice

This repository contains a modified version of the DELTA OMEGA open hardware
project originally published at:

https://github.com/unspecworks/delta-omega

Modified source location:

https://github.com/wZuck/delta-omega

Original repository baseline: commit `ddba616`.

Modification date: 2026-10-17.

Brief description of modifications:

- Replaced the ULP switch scheme with Gateron KS-33 Low Profile 3.0 five-pin
  switches in a direct-solder configuration.
- Added SOD-323 diode placements and regenerated the left, right, and panel
  PCB routing and fabrication files.
- Added Rev5 case clearance geometry and a keycap fit envelope.
- Added firmware configuration, verification scripts, bilingual
  documentation, and manufacturing reproducibility information.
