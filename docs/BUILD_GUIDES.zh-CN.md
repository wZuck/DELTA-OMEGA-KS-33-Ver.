# 装配指南

本文档介绍**手工焊接版本**的装配流程。

## 所需工具与材料

- 电烙铁
- 焊锡
- 助焊剂
- 通风设备
- 刀具或精密剪钳
- 硅胶或氰基丙烯酸酯胶水（用于磁铁）
- 万用表

如果使用邮票孔拼板，还需要：

- 钳子
- 口罩
- 砂纸

> [!NOTE]
> 打磨 PCB 时会产生细小粉尘，请做好防护。

> [!CAUTION]
> 始终把安全放在首位。良好通风、整洁工作区和合适的防护装备都是必需条件。

## 电源开关

![电源开关](./images/powerswitch.png)

1. 先在其中一个宽焊盘上预上锡。
2. 放好开关，重新熔化焊锡，将其临时固定。
3. 焊接另一侧的宽焊盘。
4. 最后焊接三个较小的引脚。

正确的方向和对齐非常重要，封装上的定位结构会辅助定位。

> [!CAUTION]
> 整个装配过程中都要让电源开关保持在 **OFF 位置（拨到最右侧）**。

## 复位开关

![复位开关](./images/resetswitch.png)

流程与电源开关基本相同：

1. 先给一个焊盘预上锡。
2. 放好开关，重新熔化焊锡固定。
3. 焊接其余三个焊盘。

同样需要确认方向和位置，封装定位结构会提供帮助。

## LED（可选）

![LED](./images/led.png)

1. LED 有极性。即使尺寸相同，不同厂商的极性标记也可能不同，焊接前请核对对应数据手册。按照丝印标记放置 LED：封闭一侧对应负极（−），开口一侧对应正极（+）。
2. 先给一个焊盘上锡，放好 LED 后重新熔化焊锡固定，再焊接另一端。
3. LED 颜色可根据偏好选择。左右板的 R、G、B 丝印对应相同的 MCU 引脚。

> [!CAUTION]
> LED 对热量敏感。请确认合适的焊接温度，并尽量缩短加热时间。

### LED 电阻

![LED 电阻](./images/led_resistors.png)

1. 为三颗 LED 安装三只电阻。电阻无极性，不要求方向。
2. 先给一个焊盘上锡，放好电阻并固定，再焊接另一端。

## ESD 保护（可选）

![ESD 保护](./images/esd_rc.png)

1. 安装 ESD 保护电容和电阻。板上有两个位置，电容和电阻可以互换放置，二者均无极性。
2. 与前面的贴片元件相同，先预上锡、固定，再焊接另一端。

## 二极管

![二极管](./images/diodes.png)

Rev5 每个键位使用一只 **SOD-323 1N4148WS** 二极管。二极管位于轴体外侧，不会与 KS-33 轴座发生干涉。

1. 方向非常重要。将二极管阴极标记与焊盘 1 和 PCB 丝印对齐。
2. 先给一个焊盘上锡，放好二极管，再焊接另一端。
3. 安装轴体前，用放大镜或显微镜检查所有焊点。

## 轴体

![Rev5 KS-33 PCB](./images/rev5_ks33_left.png)

Rev5 使用直焊式 Gateron KS-33 Low Profile 3.0，不使用热插拔座。

1. 焊接前先干装每个轴体，五个定位结构都必须无阻力插入。
2. 确认轴体完全贴合 PCB，轴心方向没有偏转。
3. 从 PCB 背面焊接一个电气脚，然后检查轴体是否仍保持对齐。
4. 焊接第二个电气脚。
5. 不要向中心孔或定位孔中填锡。
6. 将两个电气脚剪到 PCB 背面剩余不超过 0.5 mm，并在安装底盖前绝缘所有裸露金属。

- 中心孔为 5.0 mm。
- 两个定位孔为 1.70 mm，位于 ±5.08 mm。
- 两个电气脚使用标准 MX 坐标。
- 电气脚长 3.0 mm，使用 1.6 mm PCB 时剪脚前会从背面伸出约 1.4 mm。

> [!TIP]
> 每安装一个轴体，都用万用表通断或二极管档检查轴体与串联二极管。外壳装配完成后再排查会困难得多。

## MCU 控制器

![Seeed XIAO nRF52840](./images/xiao_summary.png)

1. **先刷入固件**，确认 MCU 工作正常。
2. 放好 MCU。如有需要，可在右上角和左下角插入排针辅助定位，焊接完成后拆除。
3. 焊接 XIAO 四周的邮票孔焊盘。

> [!WARNING]
> 焊接**左板外侧边缘**时，应尽量减少焊锡，避免形成可能接触铝合金外壳的焊锡凸起。

![MCU 背面](./images/xiao_back.png)

4. 在 PCB 背面焊接另外两个连接点：电池和复位。
5. 与轴体相同，确保焊锡同时连接 XIAO 和 PCB。

![MCU 背面](./images/xiao_back2.png)

6. 如需使用 LED，焊接下方附加引脚。

## 电池

![电池](./images/battery.png)

> [!CAUTION]
> 开始前确认电源开关处于 **OFF**。

> [!WARNING]
> 锂聚合物电池存在安全风险。即使轻微损坏也可能导致热失控。应避免短路、穿刺和冲击；操作不当可能造成严重伤害或财产损失。

1. 本设计不使用 JST 或 Molex 连接器，电池线直接焊接到 PCB。
2. 按实际长度剪线，剥去 1–2 mm 绝缘层并给线头上锡。
3. 再次确认极性：红色为正极，黑色为负极。
4. 使用 RTV 硅胶、Kapton 胶带或其他可靠方式绝缘正极。

## 磁铁（可选）

![磁铁](./images/magnets.png)

安装磁铁时，必须保证左右外壳的极性**正确对应**，合拢时相互吸引。

使用**硅胶**或**氰基丙烯酸酯胶水**固定磁铁。

## 外壳装配

![装配](./images/case_assembly.png)

1. 让外壳稍微向后倾斜。
2. 先对齐后部接口，再放下前部。

![外壳固定点](./images/case_mounts.png)

3. 使用螺丝将 PCB 固定到外壳。拧紧即可，不要过度用力。
4. 如果使用上盖或装饰板，应在拧紧螺丝前放好。

## 完成

![背面接口](./images/back_ports.png)

装配完成。
