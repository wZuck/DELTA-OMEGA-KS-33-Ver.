# 外壳

Rev5 外壳基于 Rev2 外形，螺丝孔位保持不变，但每个 KS-33 轴位增加了 `15.6 mm`、`r2 mm` 圆角让位。制造时请使用 Rev5 专用 STEP。

- [Rev5 机械说明](../docs/MECHANICAL.zh-CN.md)
- [键帽允许包络](./delta_omega_rev5_keycap_envelope.step)

### 默认外壳 STEP 文件

- `delta_omega_rev5_left.step`
- `delta_omega_rev5_right.step`

原始 `delta_omega_rev2_left.step` 和 `delta_omega_rev2_right.step` 保留为设计来源。

## 如何下单

本说明基于 **JLC CNC**。其他 CNC 厂商的要求可能略有不同，但大多数规格基本一致。

- **材料**：6061 铝合金或同类材料
- **表面处理**：推荐喷砂 + 阳极氧化
- **最严公差**：ISO 2768（中等）即可
- **表面粗糙度**：Ra 3.2 即可
- **螺纹**：需要。下单时务必上传左右外壳对应的螺纹标注图
