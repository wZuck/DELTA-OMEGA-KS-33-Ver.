# DELTA OMEGA

A portable low-profile wireless 3×5+2 split keyboard.


## Overview

- Switch support: Gateron KS-33 Low Profile 3.0, five-pin MX PCB layout
- 34 keys, splayed and staggered with 18 × 17 mm key pitch
- Wireless
- CNC aluminum case

## Documentation

> [!NOTE]
> Rev5 is a **five-pin low-profile MX** build. It keeps the compact 18 × 17 mm layout, so keycap footprint must be checked before ordering: standard 19.05 mm-spaced MX keycaps can interfere between rows. The original Rev4 ULP PCB and Gerbers remain in the repository for reference.
